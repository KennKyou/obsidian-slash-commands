# Slash Commands 插件

## 簡介
Slash Commands 是一個為 Obsidian 設計的插件，它為您帶來類似 Notion 的斜線命令功能。通過簡單的斜線輸入，您可以快速訪問各種編輯功能，提升您的筆記效率。

## 功能特點
- 支援斜線命令快速輸入
- 提供多種常用編輯功能
- 與 Obsidian, VitePress 整合

## 安裝方法
### 方法一：透過 Obsidian 社群插件安裝
1. 在 Obsidian 中開啟設定
2. 進入社群插件選項
3. 搜尋 "Slash Commands"
4. 點擊安裝按鈕
5. 啟用插件

### 方法二：手動安裝
1. 前往 [Releases](https://github.com/KennKyou/obsidian-slash-commands/releases) 頁面下載最新版本
2. 下載以下文件：
   - `main.js`
   - `manifest.json`
   - `styles.css`
3. 在您的 Obsidian 中創建以下目錄（如果不存在）：
   - `<vault>/.obsidian/plugins/slash-commands`
4. 將下載的文件放入該目錄中
5. 在設定中啟用插件

## 使用方法
在編輯器中輸入 `/` 即可觸發命令選單，您可以：
- 使用滑鼠選擇命令

## 系統需求
- Obsidian 版本：1.0.0 或以上
- 作業系統：Windows、macOS、Linux
